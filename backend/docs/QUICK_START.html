📋 Overview

Interlock es una plataforma de orquestación ofensiva de próxima generación que integra múltiples lenguajes de programación optimizados para máxima eficiencia y seguridad:

  • C++23 - Motor de inferencia RDT con aceleración GPU (Metal)
  • Rust - Criptografía Post-Cuántica (PQC) con seguridad de memoria
  • Go - Orquestación masiva de swarms (5000+ agentes concurrentes)
  • Swift - Middleware seguro con interop bidireccional C++
  • Zig - Generación polimórfica de payloads
  • C/ASM - Shield engine y syscalls de bajo nivel
  • TypeScript/Perl - Web intelligence y data surgery
  • Coq/Isabelle/HOL - Verificación formal

⚡ Quick Start (5 minutos)

1. Verificar Sistema

./verify_production.sh

Esto verificará que todos los requisitos previos están instalados.

2. Compilar

./build.sh

Tiempo estimado: 15-30 minutos (depende del hardware)

3. Desplegar

./deploy.sh start

Iniciará todos los servicios en producción.

4. Verificar

./deploy.sh status

Mostrará el estado de todos los componentes.

🔨 Build System

Compilación Limpia

./build.sh clean && ./build.sh

Compilación Incremental

cd build/cmake && make -j8

Compilar solo módulos específicos

cd build/cmake && make interlock_core
cd build/cmake && make atlas_go
cd build/cmake && make interlock_core_tests
💡 Tip: El parallelismo se detecta automáticamente. Para forzar un número específico de threads: PARALLEL_JOBS=4 ./build.sh

🚀 Deployment

Iniciar Servicios

./deploy.sh start

Verificar Estado

./deploy.sh status

Ver Logs

tail -f /var/log/interlock/*.log

Detener Servicios

./deploy.sh stop

Reiniciar (Graceful)

./deploy.sh restart
ℹ️ Nota: Todos los logs se guardan en /var/log/interlock/. El nivel de log en producción se establece en "warning" para minimizar ruido.

🌉 Infrastructure Components

Autonomous Breadcrumb Buffer (ABB)

Buffer circular lock-free persistente en /dev/shm/interlock_abb_prod (256 MB).

Registra todas las transiciones entre módulos políglotas para auditoría post-crash.

# Inspeccionar ABB
python3 tools/abb_inspector.py inspect 50

# Analizar patrones
python3 tools/abb_inspector.py analyze

IPC Bridge Unificado

Sistema de comunicación inter-lenguajes mediante Unix Domain Sockets (UDS).

# Ver sockets activos
ls -la /tmp/interlock_ipc_*

# Monitorear conexiones
lsof | grep interlock_ipc

Swift-C++ Interop

Integración nativa sin wrappers, aprovechando Swift 5.9+ para importación directa.

📊 Monitoring & Debugging

Health Checks

  • Core C++ ejecutándose: ps aux | grep interlock_core
  • IPC Sockets: ls /tmp/interlock_ipc_*
  • ABB accesible: ls -la /dev/shm/interlock_abb_prod
  • Database conectada: Ver logs de core

Performance Metrics (M4 Pro)

Métrica Expected
Latencia IPC <100µs
ABB Throughput 1M writes/sec
Agents concurrentes 5000+
Startup Time ~3 segundos

Debugging con DTrace (macOS)

# Rastrear syscalls del Core
sudo dtrace -n 'syscall:::entry { @[execname] = count(); }' -p $(pgrep interlock_core)

# Rastrear boundary probes (transiciones)
sudo dtrace -P 'pid$target:::entry' -c './deploy.sh start'

🔧 Troubleshooting

Build falla en CMake

Problema: Error de configuración de CMake
Solución:
rm -rf build/cmake/CMakeCache.txt
./build.sh

IPC Timeout

Problema: Los componentes no pueden comunicarse
Solución:
# Verificar sockets
ls -la /tmp/interlock_ipc_*

# Si no existen, reiniciar
./deploy.sh restart

ABB no accesible

Problema: /dev/shm/interlock_abb_prod no existe
Solución:
rm -f /dev/shm/interlock_abb_prod
./deploy.sh restart

Core se cuelga

Solución: Revisar logs de detalle
tail -100 /var/log/interlock/core.log
tail -100 /var/log/interlock/atlas.log
